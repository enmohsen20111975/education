## 📐 البيان الهندسي للمشروع

### التعريف المعماري

مشروع **SmartEdu v2.0** هو منظومة برمجية متكاملة تجمع بين قسمين رئيسيين:

| القسم | الوظيفة | الحالة |
|-------|---------|--------|
| **المنصة التعليمية** | عرض محتوى تعليمي تفاعلي للمرحلة الثانوية المصرية | مكتمل |
| **مصنع الفيديو التعليمي** | تحويل الكتب PDF → نصوص → محتوى منظم → فيديوهات | مكتمل (مرحلة الاستخراج والإنتاج) |

### المواصفات التقنية

```
┌─────────────────────────────────────────────────────────────┐
│                    البنية التقنية                           │
├─────────────────────────────────────────────────────────────┤
│ Framework:     Next.js 16 (App Router)                      │
│ Language:      TypeScript 5 (Strict)                        │
│ Styling:       Tailwind CSS 4 + shadcn/ui (New York)       │
│ Database:      Prisma ORM + SQLite (محلي)                   │
│ State:         Zustand (Client) + TanStack Query (Server)   │
│ Animations:    Framer Motion 11                             │
│ Icons:         Lucide React                                 │
│ OCR:           Tesseract.js + pdfjs-dist                    │
│ LLM:           LM Studio (Port 1234) + Ollama (Port 11434) │
│ Notifications: Sonner (Toast)                              │
│ Theme:         next-themes (Dark/Light/System)             │
└─────────────────────────────────────────────────────────────┘
```

## 🚀 التشغيل السريع

```bash
# 1. استنساخ المشروع
git clone https://github.com/enmohsen20111975/education.git
cd education

# 2. تثبيت التبعيات
bun install

# 3. تهيئة قاعدة البيانات
bun run db:push

# 4. تشغيل خادم التطوير
bun run dev
```

> **المنفذ:** `http://localhost:3000`

### المتطلبات الأساسية

| الأداة | الإصدار | الغرض |
|-------|---------|-------|
| Node.js | ≥ 18.18 | بيئة التشغيل |
| Bun | أحدث إصدار | مدير الحزم |
| SQLite | مدمج | قاعدة البيانات |

### متطلبات إضافية (للمصنع)

| الأداة | المنفذ | الغرض |
|-------|-------|-------|
| LM Studio | 1234 | تشغيل نماذج LLM المحلية (Qwen2.5) |
| Ollama | 11434 | تشغيل نماذج بديلة (Deepseek Coder) |
