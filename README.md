# 🎓 منصة الثانوية التفاعلية - Egyptian Interactive High School Platform

## 📋 نظرة عامة | Overview

منصة تعليمية شاملة للمرحلة الثانوية المصرية، تدعم جميع السنوات الدراسية والتخصصات مع محتوى تفاعلي ومحاكيات علمية.

**An comprehensive educational platform for Egyptian secondary schools, supporting all academic years and specializations with interactive content and scientific simulators.**

### الجداول الرئيسية | Main Tables

```
AcademicYear (السنوات الدراسية)
├── id: String
├── nameAr: String
├── nameEn: String
├── code: String

Specialization (التخصصات)
├── id: String
├── nameAr: String
├── nameEn: String
├── code: String
└── order: Int

Semester (الفصول الدراسية)
├── id: String
├── nameAr: String
├── nameEn: String
├── code: String
└── order: Int

Subject (المواد الدراسية)
├── id: String

├── nameEn: String

├── icon: String
├── color: String
├── yearId: String
├── specializationId: String?

├── id: String
├── subjectId: String

├── nameEn: String

└── order: Int

├── id: String

├── id: String

└── order: Int

Concept (المفاهيم)
├── id: String
├── lessonId: String
├── termAr: String

├── definitionEn: String

Formula (القوانين)
├── id: String

Example (الأمثلة)
├── id: String

├── solutionEn: String

Question (الأسئلة)
├── id: String

├── questionEn: String

Simulator (المحاكيات)
├── id: String
├── nameAr: String
├── nameEn: String
├── slug: String
├── type: String
├── descriptionAr: String
├── descriptionEn: String
├── icon: String?
└── difficulty: String
```

## 🚀 كيفية التشغيل | How to Run

```bash
# تثبيت المتطلبات
bun install

# تشغيل قاعدة البيانات
bun run db:push

# تشغيل الـ seeding
bunx tsx scripts/seed-first-year.ts
bunx tsx scripts/seed-second-year.ts
bunx tsx scripts/seed-third-year.ts

# تشغيل المشروع
bun run dev
```
