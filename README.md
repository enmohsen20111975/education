# 🎓 منصة الثانوية التفاعلية - Egyptian Interactive High School Platform

## 📋 نظرة عامة | Overview

منصة تعليمية شاملة للمرحلة الثانوية المصرية، تدعم جميع السنوات الدراسية والتخصصات مع محتوى تفاعلي ومحاكيات علمية.

**A comprehensive educational platform for Egyptian secondary schools, supporting all academic years and specializations with interactive content and scientific simulators.**

- **Database:** SQLite
- **State:** Zustand, TanStack Query
- **Animations:** Framer Motion

## 📝 ملاحظات | Notes

1. كل درس يحتوي على:
   - مقدمة تعليمية (عربي/إنجليزي)
   - ملخص الدرس
   - أهداف الدرس
   - المفاهيم الأساسية
   - القوانين والمعادلات (للمواد العلمية)
   - أمثلة محلولة
   - أسئلة اختيار من متعدد
   - محاكيات تفاعلية (حسب المادة)

2. المحتوى مبني على منهج الوزارة المصرية

3. النظام يدعم RTL للغة العربية

4. يمكنك التبديل بين العربية والإنجليزية
