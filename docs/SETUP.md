## 📥 خطوات التثبيت

### الخطوة 1: استنساخ المشروع

```bash
git clone https://github.com/enmohsen20111975/education.git
cd education
```

### الخطوة 2: تثبيت التبعيات

```bash
bun install
```

> هذا سيُثبّت جميع الحزم المُعلنة في `package.json` (~67 حزمة)

### الخطوة 3: تهيئة قاعدة البيانات

```bash
# مزامنة مخطط Prisma مع SQLite
bun run db:push

# توليد Prisma Client
bun run db:generate
```

> قاعدة البيانات ستُنشأ تلقائياً في `db/custom.db`

### الخطوة 4: تهيئة البيانات (اختياري)

```bash
# تهيئة بالبيانات التجريبية الكاملة
bun run db:seed

# أو إعادة تعيين كاملة
bun run db:reset
```

### الخطوة 5: تشغيل الخادم

```bash
bun run dev
```

> الخادم سيعمل على `http://localhost:3000`

## 🤖 إعداد خدمات الذكاء الاصطناعي

### LM Studio (المُوصى به)

#### التثبيت
1. تحميل من [lmstudio.ai](https://lmstudio.ai)
2. تثبيت التطبيق
3. تشغيله

#### تحميل النموذج المطلوب

```
النموذج المطلوب: Qwen2.5 7B Instruct
الحجم: ~4.5 GB
الغرض: تنظيم المحتوى التعليمي + توليد النصوص
```

#### إعداد الاتصال

```
1. افتح LM Studio
2. انتقل لتبويبة "Local Server"
3. تأكد أن المنفذ = 1234
4. اضغط "Start Server"
5. اختبر: GET http://localhost:1234/v1/models
```

### Ollama (اختياري)

#### التثبيت
```bash
# Windows
تحميل من ollama.com

# التشغيل (بعد التثبيت)
ollama serve
```

#### تحميل النماذج

```bash
# النموذج الأساسي (توليد أكواد)
ollama pull deepseek-coder-v2:16b

# بديل أخف
ollama pull qwen2.5-coder:7b
```

#### المنافذ الافتراضية

| الخدمة | المنفذ | نقطة الفحص |
|--------|-------|-----------|
| LM Studio | 1234 | `GET /v1/models` |
| Ollama | 11434 | `GET /api/tags` |

## 🏭 إعداد المصنع

### بدون خدمات AI (الوضع الأساسي)

المصنع يعمل جزئياً بدون خدمات AI:
- ✅ رفع PDF
- ✅ استخراج النصوص (OCR) — لا يحتاج AI
- ❌ تنظيم المحتوى — يحتاج LLM
- ✅ توليد الامتحانات — محلي (من keyPoints)
- ✅ توليد المواد — محلي (من keyPoints)
- ✅ توليد الملخصات — محلي (من content)
- ❌ توليد الصوت — يحتاج TTS
- ❌ توليد الفيديو — يحتاج Video AI

### مع خدمات AI (الوضع الكامل)

اتبع إعداد LM Studio أو Ollama أعلاه، ثم:
1. افتح المصنع في المتصفح
2. اذهب لتبويبة "النماذج"
3. تحقق من حالة الاتصال (يجب أن تكون أخضر)
4. ابدأ برفع كتاب PDF

## ⚠️ استكشاف الأخطاء

### المشكلة: OCR لا يعمل

```
السبب: Tesseract.js يحتاج تحميل بيانات اللغة عند أول استخدام
الحل: تأكد من اتصال الإنترنت عند أول تشغيل
```

### المشكلة: LLM لا يستجيب

```
السبب 1: LM Studio غير مُشغّل
الحل: شغّل LM Studio → Local Server → Start Server

السبب 2: المنفذ مختلف
الحل: تحقق من المنفذ في SettingsTab
```

### المشكلة: صفحة بيضاء

```
السبب: خطأ في الترجمة (hydration)
الحل: تحقق من dev.log
```

### المشكلة: قاعدة البيانات مقفلة

```
السبب: أكثر من عملية تحاول الكتابة
الحل: connectionLimit = 1 في db.ts (محل مسبقاً)
```

## 📱 اختبار التشغيل

بعد التثبيت الناجح:

1. **افتح المتصفح** على `http://localhost:3000`
2. **ستظهر لوحة المصنع** (التبويبة الرئيسية)
3. **تحقق من حالة الخدمات**:
   - اذهب لتبويبة "النماذج"
   - LM Studio يجب أن يكون متصلاً (أخضر)
4. **اختبار OCR**:
   - اذهب لتبويبة "المصادر"
   - ارفع ملف PDF صغير
   - اذهب لتبويبة "الاستخراج"
   - اضغط "استخراج"
   - راقب شريط التقدم
5. **اختبار LLM**:
   - بعد اكتمال OCR
   - اضغط "تنظيم"
   - راقب التقدم
6. **عرض النتائج**:
   - اذهب لتبويبة "المحتوى"
   - تصفح الوحدات والدروس
