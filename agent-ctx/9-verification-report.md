## الخطأ المكتشف والإصلاح

### المشكلة:
```
Export motionComparisonData doesn't exist in target module
```

كان هناك خطأ في ملف `LessonView.tsx` حيث تم استيراد `motionComparisonData` من ملف `Infographic.tsx`، لكن هذا الاسم غير موجود. الاسم الصحيح هو `speedComparisonData`.

### الإصلاح:
تم تغيير الاستيراد من:
```typescript
import { Infographic, energyCircleData, atomTimelineData, motionComparisonData } from "@/components/Infographic";
```

إلى:
```typescript
import { Infographic, energyCircleData, atomTimelineData, speedComparisonData } from "@/components/Infographic";
```

وكذلك تغيير استخدام `motionComparisonData` إلى `speedComparisonData` في السطر 165.
