    24→## 🤖 نظام الـ 3 AI Agents بالتوازي
    25→
    26→### لماذا 3 Agents؟
    27→
    28→محاولة جعل AI واحد يعمل كل شيء = فشل. كل Agent له تخصص واحد وواضح.
    29→
    30→```
    31→┌─────────────────────────────────────────────────────────────┐
    32→│  Agent 1: "المستخرج" (Extractor)                            │
    33→│  الأدوات: Ollama + Qwen2-VL:7b (محلي)                     │
    34→│  المهمة: قراءة صفحات الكتب (صور) → استخراج المحتوى الخام    │
    35→│  المدخلات: صور PNG (صفحات الكتب)                          │
    36→│  المخرجات: ملفات JSON خام (Raw)                           │
    37→│  السرعة: 30 ثانية/صفحة (مع Cooldown)                      │
    38→└─────────────────────────────────────────────────────────────┘
    39→                              ↓
    40→┌─────────────────────────────────────────────────────────────┐
    41→│  Agent 2: "المدقق" (Validator)                              │
    42→│  الأدوات: Ollama + Gemma3:4b (محلي) + Python Scripts      │
    43→│  المهمة: Cross-Validation + Automated Formula Check       │
    44→│  المدخلات: JSON خام + صورة الصفحة الأصلية                 │
    45→│  المخرجات: JSON مصحح + تقرير ثقة (Confidence Score)      │
    46→│  السرعة: 20 ثانية/صفحة                                    │
    47→└─────────────────────────────────────────────────────────────┘
    48→                              ↓
    49→┌─────────────────────────────────────────────────────────────┐
    50→│  Agent 3: "الباني" (Builder)                                │
    51→│  الأدوات: Google AI Studio (Gemini) + Z.ai (Zed)          │
    52→│  المهمة: تحويل JSON → Markdown نهائي (6 Chunks) + كود      │
    53→│  المدخلات: JSON مصحح من Agent 2                           │
    54→│  المخرجات: Markdown + سكريبت فيديو + كود المنصة            │
    55→│  السرعة: 5 دقائق/درس (Markdown) + 1-3 أيام/Module (كود)    │
    56→└─────────────────────────────────────────────────────────────┘
    57→```

    59→### قواعد التوازي
    60→
    61→1. **Agent 1 و Agent 2 يشتغلوا بالتوازي:** لما Agent 1 يخلص صفحة 1 ويحفظها، Agent 2 يبدأ يدقق صفحة 1 في نفس الوقت اللي Agent 1 بيشتغل فيه على صفحة 2
    62→2. **Agent 3 ما يبدأش إلا لما يكون عنده 7 دروس (فصل كامل) مصححة:** مش هنبني كود على محتوى ناقص
    63→3. **الإنسان (أنت) يتدخل في 3 نقاط فقط:**

    66→   - قراءة الـ Markdown النهائي قبل رفعه - 30 دقيقة/درس

   145→## 🔄 سير عمل المحتوى (Content Pipeline) - مطور بالكامل
   146→
   147→### المرحلة 1: استخراج المحتوى (أسبوع 1)
   148→
   149→**الهدف:** 7 دروس (الفصل الأول: التيار الكهربي) من كتاب المعاصر + التفوق + الامتحان
   150→
   151→#### اليوم 1: تحضير الكتب
   152→
   153→1. **جمع الكتب (2-3 ساعات):**
   154→   - افتح Telegram → ادخل `t.me/Thanwya_PDF` أو `t.me/kotob_3ama`
   155→   - حمل: `المعاصر فيزياء 3 ثانوي.pdf` + `الامتحان فيزياء 3 ثانوي.pdf` + `التفوق فيزياء 3 ثانوي.pdf`
   156→   - حمل كتاب الوزارة من `ekb.eg` (تسجيل بالرقم القومي)
   157→   - حطهم في `content-extractor/books/`
   158→
   159→2. **تحويل الفصل الأول لصور (30 دقيقة):**
   160→   - شغل `01_pdf_to_images.py`
   161→   - المدخل: `books/moaser-physics-3.pdf` (صفحات 15-45 مثلاً = الفصل الأول)
   162→   - المخرج: `pages/page_015.png` إلى `pages/page_045.png`
   163→   - **إعدادات ثابتة:** DPI 150، Max Size 512px، صيغة PNG
   164→
   165→#### اليوم 2-3: Agent 1 (المستخرج) يشتغل
   166→
   167→**السكريبت `02_extract_page.py` يشتغل:**
   168→
   169→```
   170→لكل صفحة في pages/:
   171→    1. يرسل صفحة واحدة بس لـ Qwen2-VL:7b (Ollama)
   172→    2. ينتظر 10 ثواني (Cooldown)
   173→    3. يحفظ النتيجة فوراً في raw-json/page_XXX.json
   174→    4. يطبع: "صفحة 15/30 - خلصت - نوع: lesson"
   175→    5. لو قفل الجهاز: يشغل تاني، يكمل من آخر صفحة (Resume)
   176→```
   177→
   178→**الـ Prompt اللي يرسله Agent 1 للموديل:**
   179→
   180→> "أنت قارئ كتب مدرسية مصري متخصص. اقرأ هذه الصفحة من كتاب الفيزياء للثانوية العامة واستخرج المعلومات في JSON صحيح فقط.
   181→>
   182→> المطلوب:
   183→> 1. `page_type`: "lesson" أو "exercise" أو "formula" أو "empty"
   184→> 2. `lesson_title`: عنوان الدرس (لو موجود)
   185→> 3. `content_summary`: ملخص بسيط لمحتوى الصفحة
   186→> 4. `formulas`: ["$I = \frac{Q}{t}$", "$V = IR$"] (LaTeX بين $)
   187→> 5. `definitions`: [{"term": "شدة التيار", "definition": "..."}]
   188→> 6. `examples`: [{"question": "...", "solution": "..."}]
   189→> 7. `exercises`: ["سؤال 1", "سؤال 2"]
   190→> 8. `figures_description`: وصف الرسومات
   191→> 9. `tables_description`: وصف الجداول
   192→> 10. `source_hints`: أفكار من الكتاب (مش نص حرفي)
   193→>
   194→> قواعد:
   195→> - JSON صحيح فقط. لا نص خارج JSON.
   196→> - الصيغ: LaTeX بين $ $
   197→> - لا تخترع معلومات. لو الصفحة فارغة: `{"page_type": "empty"}`
   198→> - اكتب بالعربية الفصحى (مش عامية)."
   199→
   200→**الوقت المتوقع:** 30 صفحة × 30 ثانية = 15 دقيقة تشغيل فعلي + Cooldown = ~45 دقيقة
   201→
   202→#### اليوم 3-4: Agent 2 (المدقق) يشتغل بالتوازي
   203→
   204→**السكريبت `03_cross_validate.py`:**
   205→
   206→```
   207→لكل ملف في raw-json/:
   208→    1. يقرأ JSON من Agent 1
   209→    2. يرسل نفس الصفحة (الصورة) لـ Gemma3:4b (موديل مختلف)
   210→    3. يقارن النتيجتين:
   211→       - لو الصيغ متطابقة 100% → Confidence: HIGH
   212→       - لو اختلفوا في رقم → Confidence: MEDIUM → علامة "⚠️ رقم مختلف"
   213→       - لو اختلفوا في صيغة → Confidence: LOW → علامة "⚠️ صيغة مختلفة"
   214→    4. يحفظ في validated-json/page_XXX.json
   215→```
   216→
   217→**السكريبت `04_auto_validate.py` (Python - لا يحتاج AI):**
   218→
   219→```
   220→لكل ملف في validated-json/:
   221→    1. يفحص LaTeX: هل `$...$` مكتوبة صح؟
   222→    2. يحسب الأمثلة الحسابية: Q=30, t=5 → I=6A. لو الموديل كتب 5A = غلط
   223→    3. يفحص الوحدات: A, V, Ω, C, s
   224→    4. يفحص التناقضات: صفحة 5: I=Q/t، صفحة 6: I=Q×t = تناقض
   225→    5. يولد تقرير: validation-report.json
   226→```
   227→
   228→**الوقت المتوقع:** 30 صفحة × 20 ثانية = 10 دقائق + 5 دقائق للفحص الآلي = 15 دقيقة
   229→
   230→#### اليوم 5: المراجعة البشرية (أنت - 2-3 ساعات فقط)
   231→
   232→**لا تفحص كل حاجة. افحص العينة فقط:**
   233→
   234→1. افتح `validation-report.json`
   235→2. دور على الصفحات اللي عليها علامة "⚠️" (Confidence: LOW أو MEDIUM)
   236→3. **افحص الحتة دي بس:**
   237→   - مثلاً: 5 صفحات من 30 (مش 30 صفحة)
   238→   - 2-3 دروس من 7 (مش 7 دروس)
   239→4. قارن الصيغ المختلفة بكتاب الوزارة (المرجع الرسمي)
   240→5. صلح في `validated-json/` يدوياً (مش لازم تكتب الكل - عدل الرقم الغلط بس)
   241→
   242→**الوقت:** 2-3 ساعات (مش سنة)
   243→
   244→#### اليوم 6-7: الدمج + Markdown
   245→
   246→**السكريبت `05_merge_pages.py`:**
   247→
   248→```
   249→المدخل: validated-json/ + book-index.json (أنت هتكتبه يدوياً - 10 دقائق)
   250→
   251→book-index.json:
   252→{
   253→  "lessons": [
   254→    {"id": "phy-3-1-1-01", "title": "مقدمة في الكميات الفيزيائية", "pages": [15, 16, 17]},
   255→    {"id": "phy-3-1-1-02", "title": "شدة التيار الكهربي", "pages": [18, 19, 20, 21]},
   256→    ...
   257→  ]
   258→}
   259→
   260→السكريبت يدمج JSON الصفحات (15+16+17) → درس واحد JSON

   262→
   263→**السكريبت `06_generate_markdown.py`:**
   264→
   265→```
   266→المدخل: merged-lessons/lesson-01.json
   267→المخرج: final-markdown/lesson-01.md (الـ 6 Chunks)
   268→
   269→الـ 6 Chunks:
   270→1. 🎬 Chunk 1: سكريبت الفيديو (10-15 دقيقة، بالعامية المصرية)
   271→2. 🧠 Chunk 2: الخريطة الذهنية (JSON للعقد والفروع)
   272→3. 📖 Chunk 3: الشرح المقروء + الانفوجرافيك (Markdown + HTML)
   273→4. 🧪 Chunk 4: وصف المحاكي (JSON للـ Simulator Config)
   274→5. ⚡ Chunk 5: بنك الأسئلة (5 أسئلة: 3 MCQ + 1 Numerical + 1 Conceptual)
   275→6. 🏆 Chunk 6: بطاقات المراجعة (Flashcards YAML)
