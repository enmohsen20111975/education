    23→    23→## 1. نظرة عامة على النظام
    24→    24→
    25→    25→### المشكلة الحالية
    26→    26→- المشروع الحالي `video-factory` يعمل بـ "درس واحد في كل مرة" (ohm-law فقط)
    27→    27→- لا يوجد نظام إدارة كتب متعددة
    28→    28→- المحتوى المستخرج غير منظم في ملفات قابلة للتعديل
    29→    29→- لا يوجد محرر مرئي للمحتوى قبل توليد الفيديو
    30→    30→- عملية ربط الدروس بالفيديوهات يدوية بالكامل
    31→    31→
    32→    32→### الحل المقترح
    33→    33→نظام موحد يوفر:
    34→    34→1. **رفع كتاب كامل** (PDF ممسوح) → استخراج تلقائي للنصوص والصور والجداول والأسئلة
    35→    35→2. **محرر شامل** للمراجعة والتعديل قبل الإنتاج
    36→    36→3. **استوديو فيديو** لتوليد فيديو شرح لكل درس بضغطة زر
    37→    37→4. **إدارة مركزية** لكل الكتب والدروس والفيديوهات
    38→    38→
    39→    39→### المبادئ التوجيهية
    40→    40→- ✅ **ملف واحد قابلة للتعديل** لكل درس (JSON + Markdown)
    41→    41→- ✅ **عملية قابلة للاستئناف** في أي مرحلة (Resume Capability)
    42→    42→- ✅ **حماية اللابتوب** من الحمل الزائد (Cooldowns + Concurrency Limits)
    43→    43→- ✅ **شفافية كاملة** في الحالة (Status Tracking في كل خطوة)
    44→    44→- ✅ **لا اختراع محتوى** - الـ VLM يستخرج فقط ما في الكتاب

   288→   288→## 4. المراحل الإنتاجية الأربعة
   289→   289→
   290→   290→### المرحلة 1: Content Ingest (استيعاب المحتوى)
   291→   291→
   292→   292→**المدخلات**: ملف PDF ممسوح ضوئياً
   293→   293→**المخرجات**: master.json + ملفات الدروس + الصور
   294→   294→
   295→   295→#### الخطوات:
   296→   296→1. **رفع PDF** إلى `books/` folder
   297→   297→2. **تحويل لصور** (`pdf-to-images.py`):
   298→   298→   - DPI: 150
   299→   299→   - Max Size: 512px
   300→   300→   - Format: PNG
   301→   301→3. **استخراج المحتوى** (`extract-page.py`):
   302→   302→   - Model: qwen2-vl:7b
   303→   303→   - Cooldown: 10 ثواني بين الصفحات
   304→   304→   - GPU VRAM Limit: 7GB
   305→   305→   - Resume capability (تخطي الصفحات المعالجة)
   306→   306→4. **دمج الصفحات** (`merge-pages.py`):
   307→   307→   - تجميع الصفحات حسب الدرس
   308→   308→   - إزالة التكرارات
   309→   309→   - حساب confidence score
   310→   310→5. **توليد master.json** (`generate-master.py`):
   311→   311→   - إنشاء هيكل الوحدات والدروس
   312→   312→   - ربط الصور بالدروس
   313→   313→   - استخراج الجداول والأسئلة
   314→   314→
   315→   315→#### البرومبت المُحسّن:
   316→   316→راجع `content-extractor/config/extraction-prompt.txt` - تم تحسينه ليستخرج:
   317→   317→- تقسيم الدروس تلقائياً
   318→   318→- الصور مع وصفها
   319→   319→- الجداول كاملة
   320→   320→- الصيغ الرياضية بصيغة LaTeX
   321→   321→- الأسئلة مع إجاباتها
   322→   322→
   323→   323→### المرحلة 2: Content Editor (محرر المحتوى)
   324→   324→
   325→   325→**المدخلات**: master.json + lesson.json
   326→   326→**المخرجات**: lesson.json معدل
   327→   327→
   328→   328→#### المميزات:
   329→   329→1. **محرر نصوص غني** (Rich Text Editor):
   330→   330→   - دعم كامل للعربية
   331→   331→   - دعم LaTeX للصيغ الرياضية (KaTeX)
   332→   332→   - دعم التشكيل
   333→   333→2. **مدير الصور**:
   334→   334→   - معاينة الصور المستخرجة
   335→   335→   - إضافة صور جديدة
   336→   336→   - تعديل الأوصاف
   337→   337→   - حذف الصور غير الضرورية
   338→   338→3. **محرر الجداول**:
   339→   339→   - إضافة/حذف صفوف وأعمدة
   340→   340→   - تعديل الخلايا
   341→   341→4. **محرر الصيغ**:
   342→   342→   - معاينة LaTeX مباشرة
   343→   343→   - تعديل المتغيرات والوحدات
   344→   344→5. **محرر الأسئلة**:
   345→   345→   - 4 أنواع: MCQ, Numerical, Conceptual, True/False
   346→   346→   - تعديل الخيارات والإجابات
   347→   347→   - إضافة شرح الحل
   348→   348→
   349→   349→#### الحفظ التلقائي:
   350→   350→- كل تعديل يُحفظ فوراً في `lesson.json`
   351→   351→- نظام versions للرجوع لأي نسخة سابقة
   352→   352→
   353→   353→### المرحلة 3: Video Production (إنتاج الفيديو)
   354→   354→
   355→   355→**المدخلات**: lesson.json (مُراجع)
   356→   356→**المخرجات**: ملف MP4 مضغوط + رابط (لو R2 متاح)
   357→   357→
   358→   358→#### الخطوات:
   359→   359→1. **توليد السكريبت** (`generate-script.py`):
   360→   360→   - تحويل المحتوى لسكريبت صوتي
   361→   361→   - لهجة قابلة للاختيار (عامية/فصحى)
   362→   362→   - إضافة علامات التوقيت للمشاهد
   363→   363→2. **توليد الصوت** (`generate_tts.py`):
   364→   364→   - Edge-TTS بالصوت المختار
   365→   365→   - إخراج: MP3 + JSON timestamps
   366→   366→3. **توليد الفيديو** (Remotion):
   367→   367→   - إنشاء composition ديناميكي
   368→   368→   - تمرير props من lesson.json
   369→   369→   - مدة الفيديو = مجموع مشاهد scenes
   370→   370→4. **ضغط الفيديو** (FFmpeg):
   371→   371→   - H.264, CRF 22, preset fast
   372→   372→   - Audio: AAC 128k
   373→   373→5. **رفع الفيديو** (اختياري):
   374→   374→   - Cloudflare R2 (موافق للـ Hostinger)
   375→   375→   - تحديث `video_url` في lesson.json
   376→   376→
   377→   377→#### إدارة الطابور (Queue):
   378→   378→- نظام queue للدروس المختارة
   379→   379→- تشغيل تسلسلي (واحد تلو الآخر) لحماية الجهاز
   380→   380→- إمكانية الإيقاف المؤقت والاستئناف
   381→   381→
   382→   382→### المرحلة 4: Distribution (التوزيع)
   383→   383→
   384→   384→**المدخلات**: lesson.json + video.mp4
   385→   385→**المخرجات**: بيانات جاهزة لمنصة education
   386→   386→
   387→   387→#### آلية الربط مع منصة education:
   388→   388→1. تصدير `lesson-export.json` يحتوي:
   389→   389→   - `lesson_id`
   390→   390→   - `title`
   391→   391→   - `video_url` (رابط R2 أو local)
   392→   392→   - `summary`
   393→   393→   - `questions`
   394→   394→2. يُرفع يدوياً لمنصة education

   684→   684→
   685→   685→| الفئة | التقنية | الاستخدام |
   686→   686→|------|---------|---------|
   687→   687→| **Backend** | Node.js + Express | خادم API |
